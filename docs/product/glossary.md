# Glosario

| Término                | Significado en el panel                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Ficha                  | Registro editorial de un centro o atractivo turístico                                                               |
| Centro turístico       | Objeto del inventario institucional; no equivale a un establecimiento del catastro                                  |
| Catastro               | Inventario de establecimientos por localidad                                                                        |
| Localidad              | Opción territorial reconocida por el catálogo de la API                                                             |
| Borrador               | Trabajo guardado que aún puede corregirse                                                                           |
| En revisión            | Propuesta enviada para decisión institucional                                                                       |
| Publicado              | Versión aprobada que puede mostrar la app móvil                                                                     |
| Devolver para corregir | Retirar la propuesta de la cola y devolverla con un motivo                                                          |
| Eliminar               | Retirar lógicamente el registro del producto, conservando historial                                                 |
| Desactivar             | Cambiar la disponibilidad según el contrato, con posible reactivación                                               |
| Importar ficha         | Analizar Excel y cargar datos en el editor; este puede guardar apartados y fotos cuando existe código, sin publicar |
| Catálogo retirado      | Opción conservada como referencia histórica pero no elegible para nuevas asignaciones                               |
| Agente turístico       | Rol institucional de captura, distinto del turista                                                                  |

Usar estos términos en labels, errores y specs. Los nombres de paquetes,
proveedores y rutas técnicas pertenecen al knowledge y a diagnósticos autorizados.
