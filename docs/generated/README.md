# Referencias generadas

Este directorio queda reservado para referencias producidas desde fuentes
versionadas: contratos de API, rutas o esquemas cuando exista un generador.
No hay una exportación generada de la API en esta adopción.

Documentar generador, fuente y comando al incorporar una referencia. Cambiar la
fuente y regenerar; no corregir manualmente la salida.

Los artifacts de OpenSpec y sus integraciones tienen sus propias rutas y
procedimientos. Las specs authored de cambios describen comportamiento; las
skills `openspec-*`, comandos y prompts provienen del CLI fijado.
