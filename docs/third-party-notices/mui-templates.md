# Plantillas Material UI

El tema compartido, la pantalla de acceso y la presentación del panel adaptan las
plantillas oficiales **Dashboard** y **Sign-in** de Material UI v7.3.5, publicadas bajo
licencia MIT. Los formularios y las operaciones institucionales pertenecen a esta web.

- [Catálogo de plantillas](https://mui.com/material-ui/getting-started/templates/).
- [Tema de referencia v7.3.5](https://github.com/mui/material-ui/tree/v7.3.5/docs/data/material/getting-started/templates/shared-theme).
- [Sign-in v7.3.5](https://github.com/mui/material-ui/tree/v7.3.5/docs/data/material/getting-started/templates/sign-in).
- [Dashboard v7.3.5](https://github.com/mui/material-ui/tree/v7.3.5/docs/data/material/getting-started/templates/dashboard).
- [Licencia original](https://github.com/mui/material-ui/blob/v7.3.5/LICENSE).
